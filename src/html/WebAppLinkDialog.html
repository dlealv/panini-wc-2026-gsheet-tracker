The web app has not been deployed yet.

To deploy:

  1. Open Extensions → Apps Script.
  2. Click Deploy → New deployment.
  3. Select type: Web app.
  4. Set Description: Enter the name of the deployment.
  5. Set Execute as: Me.
  6. Set Who has access: Anyone.
  7. Click Deploy and optionally copy the URL.
  8. Return here: the URL will appear automatically.
